# P5 · 与远程引擎交叉

本地两个分类器都能差 42 个百分点（72.8% vs 30.8%）。要更稳的结论时，用 `aigc-rate-detect` 技能跑朱雀 + HF Space，把两边数字**并列**给用户，别只报一个数。

## 判断逻辑

| 本地 | 远程 | 怎么说 |
|---|---|---|
| 低 | 低 | 可以交 |
| 高 | 高 | 必须改，规则不够就重写 |
| 一高一低 | — | 说明"两把尺子不一致"，给两段数字和原因，让用户决定 |

## 使用场景

- 学校/期刊系统提交前
- 本地分与远程分打架时
- 需要更高置信度时

## 相关技能

`aigc-rate-detect`（远程检测）
