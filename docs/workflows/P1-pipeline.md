# P1 · 一键自动闭环（规则改写）

**适用场景**：分数在 `amendable`（0.56–0.85），规则改写有机会降低 AI 率。

## 命令

```bat
aigc.cmd pipeline -f 论文.docx --target 0.2 --rounds 3 --out 改后.txt
```

## 工作流程

每轮执行：
1. 检测全文，找出疑似段
2. 只改写疑似段（跳过干净段）
3. 复检改写结果

**自动停止条件**：本轮无实质下降（`--json` 输出里会出现 `"note": "本轮无实质下降，停止"`）

## 重要提示

- **不要无限加轮数**：如果连续两轮无实质下降，说明规则引擎已到天花板，应该换策略（见 P2 的 `advice` 分档判断）
- **天花板限制**：规则改写对 `saturated` 段（prob ≥ 0.99）基本无效，最多降到 0.98 左右
- **改完必须复检**：部分段规则改写后分数会反升（实测 72.8% → 73.4%）

## 跨阈值改写

如果目标是跨过阈值（如从 65% 降到 20%），规则引擎往往不够，需要用 [P1.5 本地 LLM 改写](P1.5-llm-rewrite.md)。
